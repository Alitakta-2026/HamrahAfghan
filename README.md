# همراه افغان — نسخه ۵
نسخه آماده‌سازی برای انتشار در کافه‌بازار، مایکت و بعداً Google Play.

این نسخه شامل:
- صفحه اصلی حرفه‌ای‌تر
- کیف پول آزمایشی
- خدمات پرداخت آزمایشی
- کاریابی
- مهاجرت و ویزا
- آموزش کودکان
- مراکز مهم
- پرسش و پاسخ
- حریم خصوصی و هشدارهای امنیتی
- ساختار نسخه انتشار

توجه: کیف پول و پرداخت‌ها در این نسخه شبیه‌سازی هستند و پول واقعی جابه‌جا نمی‌شود.
قبل از انتشار نسخه مالی واقعی، باید اتصال به سرویس‌دهنده پرداخت مجاز، حریم خصوصی، شرایط استفاده و الزامات مارکت بررسی و تکمیل شود.
