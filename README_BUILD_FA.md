# ساخت APK روی GitHub با گوشی

این پروژه برای ساخت APK آزمایشی آماده است.

## روش ساده
1. یک Repository جدید در GitHub بسازید.
2. تمام فایل‌های این پروژه را در شاخه `main` آپلود کنید.
3. وارد تب **Actions** شوید.
4. گردش کار **Build Hamrah Afghan APK** را اجرا کنید.
5. بعد از پایان موفق، در همان اجرای Workflow بخش **Artifacts** فایل `HamrahAfghan-debug-apk` را دانلود کنید.
6. فایل `app-debug.apk` را روی گوشی نصب و تست کنید.

این APK نسخه Debug برای تست واقعی است، نه فایل نهایی امضاشده فروشگاه.
کیف پول در این نسخه آزمایشی است و پول واقعی جابه‌جا نمی‌کند.
